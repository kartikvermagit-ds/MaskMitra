# MaskMitra — Hindi quick start

Screenshot share karne se pehle private details hide karne ka offline Windows app.

1. [MaskMitra.exe download karo](https://github.com/kartikvermagit-ds/MaskMitra/releases/latest/download/MaskMitra.exe).
2. App kholkar **Try demo**, **Capture**, **Open image** ya **Paste image** chuno.
3. Suggestion select karke **Hide** ya **Keep** dabao. **Hide matches** matching detected details ko saath hide karta hai.
4. Jo detail miss hui ho, uske upar **Hide** tool se rectangle banao.
5. **Review & export** mein poori image check karke **Copy clean image** ya **Save PNG** dabao.

App images upload nahi karta. Detection har detail nahi pakad sakti; names, faces aur QR codes automatic hide nahi hote. Undecided suggestions export mein visible rehti hain.

Windows 10/11, .NET Framework 4.8 aur automatic scan ke liye installed Windows OCR language chahiye. Manual hiding scan ke bina bhi chalegi.

Release abhi unsigned hai; SmartScreen warning aa sakti hai. Source par bharosa ho tab Windows ka **More info → Run anyway** option use kar sakte ho. Windows security band mat karo.
